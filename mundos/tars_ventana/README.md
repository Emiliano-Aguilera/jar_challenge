# tars_ventana

Office layout with a 0.60 m wide window: sill at 0.07 m, opening to 0.45 m. Camera and LiDAR can see a red box through it; normal doors still provide a route to every room. Tests seeing through a wall without treating it as a traversable door.

Start: `(0, 0, 0)`. Victims: 3. Use `rama=development`, 600 seconds, one repetition.

Walls go into /map; victims, blue distractors and senuelo_* obstacles do not.
