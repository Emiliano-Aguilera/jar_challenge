# tars_oficinas

New asymmetric office layout with two 1 m doors, three victims and a blue distractor. Every victim has reachable observation positions. Baseline for tars_desvios.

Start: `(0, 0, 0)`. Victims: 3. Use `rama=development`, 600 seconds, one repetition.

Walls go into /map; victims, blue distractors and senuelo_* obstacles do not.
