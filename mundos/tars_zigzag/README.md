# tars_zigzag

New serpentine layout with alternating wide passages, three victims and one blue distractor. Tests route completion, repeated turns and return from the far end.

Start: `(0, 0, 0)`. Victims: 3. Use `rama=development`, 600 seconds, one repetition.

Walls go into /map; victims, blue distractors and senuelo_* obstacles do not.
