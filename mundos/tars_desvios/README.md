# tars_desvios

Same walls, victims and distractor as tars_oficinas, plus three non-red obstacles absent from /map. Tests dynamic avoidance against a controlled baseline.

Start: `(0, 0, 0)`. Victims: 3. Use `rama=development`, 600 seconds, one repetition.

Walls go into /map; victims, blue distractors and senuelo_* obstacles do not.
